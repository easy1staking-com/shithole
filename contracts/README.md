# shithole/contracts

Aiken contracts for the Shithole protocol.

## Layout

```
contracts/
├── aiken.toml                 # project + deps (compiler v1.1.21, plutus v3, stdlib v3.1.0)
├── lib/shithole/
│   ├── types.ak               # ConfigDatum, ListingDatum, ListingRedeemer, MIN_LISTER_FEE
│   └── utils.ak               # compute_output_tag, signed_by (ported from jpgstore-sniper)
├── validators/
│   ├── config.ak              # multi-handler validator: mint + spend (admin updates)
│   ├── config.test.ak         # mint + spend tests + property tests
│   ├── listing.ak             # spend validator parameterized on config NFT policy
│   └── listing.test.ak        # Swap + Cancel tests + bucket math goldens
└── plutus.json                # generated by `aiken build`
```

## Commands

```sh
aiken check -D     # type-check + run tests with deny-warnings
aiken build        # produce plutus.json blueprint
aiken fmt          # format
aiken docs         # generate docs (HTML)
```

## Reference

Patterns mirror `/Users/giovanni/Development/workspace/jpgstore-sniper/src/jpgstore-sniper-onchain/`:
- `validators/settings.ak` is the multi-handler template for our `config.ak`
- `validators/snipe.ak` is the parameterized-spend template for our `listing.ak`
